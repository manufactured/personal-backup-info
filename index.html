Family site backups

A private, personal backup utility using rclone to store backups in the operator’s Google Drive.

The utility runs on the operator’s own computer. Google authorization lets it create and manage its own backup files. It requests access only to Drive files created or explicitly authorized for this app, rather than general access to the account’s existing files.

This page describes the backup utility. Backup contents are private and are not published here. The utility is not offered as a public service.
