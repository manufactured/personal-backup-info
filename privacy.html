Privacy policy

Family site backups is a personal backup utility operated by the owner of the manufactured GitHub account.

Google Drive access

The utility uses rclone and Google’s Drive API to upload, list, verify, download and manage the operator’s backup files. It requests the limited drive.file permission, covering files created or explicitly authorized for this app.

Data use and storage

File contents and metadata are used only for backup and recovery. Backup files are stored in the operator’s Google Drive account; working copies and authorization credentials are held on the operator’s computer. Backup data is not sold, used for advertising, or used to train AI models. The utility does not share it with unrelated parties. Google processes stored data under its own terms and privacy policy.

Access to Google user data is used in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

The operator controls backup retention and deletion. Authorization can be revoked through Google Account connections. Revoking access stops the utility’s authorized access; it does not automatically delete previously stored backups.

This information website

This static website has no sign-in, forms, analytics scripts or advertising. GitHub Pages hosts it and may collect ordinary request information under GitHub’s privacy statement.

Contact

The operator can be reached through the public contact options on the manufactured GitHub profile.
